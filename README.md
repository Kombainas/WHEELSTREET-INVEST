# WheelStreet Invest

Minimalus Next.js projektas su TypeScript ir Tailwind CSS.

## Paleidimas

1. **Įdiegti priklausomybes:**
   ```bash
   npm install
   ```

2. **Paleisti development serverį:**
   ```bash
   npm run dev
   ```

3. **Atidaryti naršyklėje:**
   ```
   http://localhost:3000
   ```
